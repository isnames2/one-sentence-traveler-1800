One sentence, at most 200 characters, explaining the modern internet to a
traveler from the year 1800 — using only words they could have known.

> It is a post office and a library joined into one house, where every
> letter and book in the world flies along thin wires and lands in your
> hand in one breath, for any soul to read and answer.

Bounty page: https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb

`main.py` (pure Python standard library) writes the sentence to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. The output is byte-identical on repeat runs.
